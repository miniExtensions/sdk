# Controlled Lookup ownership

Read `docs/lookup.md` before changing the controlled contract. Preserve the
legacy binding/inert API and its independent consumer checks.

`projectLookupValues` admits already-flat native arrays. Retain original result
configuration, member references, original occurrence indexes and duplicates.
Whole-array result kinds must not be scalarized or normalized through record-ID
deduplication. Preserve the native difference between an empty scalar array and
nonempty all-empty members, numeric zero, false Checkbox and zero Rating.

The SDK owns complete readonly presentation and reusable rich leaves. Native
adapters retain configuration, masking/formatting, canonical values and actual
captured resource/action authority. Do not add a native JSX renderer slot,
fabricated binding/response frame, setter, metadata publisher or SDK Form/store/
Save/controller clone. Linked tables require actual cell projections; list-card
policy is not a replacement for standalone field formatting. Preserve native
Rating grid context and complete out-of-range display.

Retirement is monotonic per actual capture. Equal values or record IDs after
A→B→A cannot renew old callbacks. Check the host at action time and cancel or
suppress stale async publication. Close remains available after retirement.
Keep legacy resource behavior unchanged when the optional owner is omitted.
Admit only declared data shapes before child effects; React nodes, refs and
undeclared event handlers are not string/image metadata.

Run focused projection, controlled Lookup, real Rich Text and resource lifetime
tests, then the normal source/coverage and package checks without changing
thresholds. `controlled-lookup-consumer-checks.mjs` verifies installed React18/19
ESM/CJS, strict types, SSR/hydration, CSS and production bundles. The maintained
browser helper verifies real trusted inputs, paint, rich runtime, focus and
stale no-effects. Native Form/controller acceptance remains separate.

Use repository resource guards on shared machines and a real task-local TMPDIR
when path guards reject a macOS `/var` alias. Treat setup errors, admission,
executed tests and acceptance as separate evidence. Preserve exact commit/tree,
archive and harness hashes. Report unrelated owner failures precisely; do not
repair another owner's runtime or call a focused pass the full umbrella.
