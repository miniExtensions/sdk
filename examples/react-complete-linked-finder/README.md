# Complete linked finder consumer

This example imports only the built public package and CSS exports. From the
SDK checkout, run `pnpm build`, then
`node examples/react-complete-linked-finder/dev.mjs` and open the printed local
URL. It uses synthetic captured host ports, canonical hidden/duplicate IDs,
admitted rich cards, data-URL images and a native-compatible cascade. The scanner
is disabled. No camera, remote image, account, API, storage or fixture is used.

Try keyboard selection, duplicate membership removal, List/Gallery/Kanban,
image failures, the two equal-label driver IDs, `slow` followed by owner
replacement, and `failure`. This is portable public-package browser evidence;
it does not qualify native Redux/transport assembly or an installed native pin.
