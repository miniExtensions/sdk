# Explicit host-authorized image annotation

UNQUALIFIED source preparation for SDK-COMPLETE-ANNOTATION-COMPOSITION.
Additive public exports/CSS/package-proof sources are prepared; runtime dependency,

ImageAnnotationField owns the picker, image decode boundary, eight-tool lazy
markerjs2 popup, scoped labels/keyboard behavior, source/editor generations and
render/upload/URL continuation. CompleteImageAnnotationField is an additive alias.
Its continuing owner and storage/append ports are explicit host contracts, not
accepted loaded Form/client objects. Existing bound upload-file-only policy stays
unchanged; annotation is not relabelled as an ordinary file-upload producer.

The application must supply a captured native owner token and continuing isCurrent
predicate. On authority/policy replacement it must supply the actual successor
owner. The component never creates authority from a DTO or token. Stable cosmetic
callbacks/value/labels do not install a second writer. Storage and append are
captured with that owner; changes in their authority require an owner replacement.

createTemporaryPng allocates at most once for one render. resolveUrl is a separate
operation and is never started after retirement. An already-started URL read may
settle, but retirement refuses append/feedback. Normal vendor render is followed
by close: close releases owned local URL/editor UI while the current rendered
upload continues. Source/owner replacement and unmount retire that continuation.
No remote cancellation, rollback, delete queue or record-Save success is implied.

appendCurrent must synchronously verify the ORIGINAL captured native owner and
operation identity, read the LATEST canonical attachment array, append once via
the original native writer and return appended/retired. It must not replace a
captured array or retarget a delayed edit to a successor. The SDK never stores
that canonical array. Reannotation appends; native readonly, capacity, image and
disableOpenFiles gates remain required at BOTH entry points.

6a4e32f7384666032d5ea178dd7a984f3d395d49. The exact Linkware notice is preserved

an additional visible link to https://markerjs.com, with a nonempty fallback
label. Scoped instance title/ARIA labels avoid changing another widget.

No vendor import occurs on SDK module import or SSR. The internal driver loader
parameter is a hermetic UNIT-test seam, not a public field prop/native UI callback.
Production component always uses ordinary lazy import('markerjs2').
The generated 64x32 bundled PNG is source fixture data; it has NOT been decoded
or rendered in a browser by this preparation.
