# Controlled Rollup localhost example

After `pnpm build`, run `node examples/react-rollup/dev.mjs` on the work device
and open http://127.0.0.1:4186. The example imports the real public SDK entry and
packaged readonly CSS. It needs no server credentials or external fixtures.

Keep a sibling draft while selecting Text, Currency, Invalid, Empty and Recovered.
Inspect literal markup, a new-tab link, localized empty, zero and array text.
The display owns no setter, Save or aggregation. Host labels are already mapped
text, not SDK linked-record hydration. Native dispatcher tests remain a separate
acceptance requirement.
